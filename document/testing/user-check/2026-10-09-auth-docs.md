# Auth and login documentation completion — 2026-10-09

## What works

- Login works through the frontend proxy with valid credentials. Incorrect passwords and unknown email addresses show the same attempt pattern.
- After three consecutive incorrect passwords, the account is locked for one minute. Further attempts are rejected during the lock. Login works after the lock expires.
- Profile password change goes through the documented gateway endpoint and keeps the current session active; other sessions are revoked.
- The login screen was captured and visually inspected against the supplied image.
- PostgreSQL migration for login-attempt tracking and lockout was applied successfully.
- Workspace `pnpm typecheck` and `pnpm build` passed for frontend, gateway, and auth service.
