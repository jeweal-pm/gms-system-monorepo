Retention invariant: an application-level user delete may hide an upload, but it must retain the object's bytes and metadata indefinitely. No date-based expiry, lifecycle purge, or automated physical deletion is allowed for `files` or user-uploaded `public` objects. Package case `GMS-ST-INT-08` directly verifies that the driver rejects physical delete requests and the bytes remain readable.

The package test source is `packages/gms-storage/test/storage.test.ts`. It covers the storage driver directly against isolated temporary filesystem roots; it does not replace service/route/database integration scenarios in the auth and partner rows.
