# SA decisions: purchase-order, SA revision 1

- Feature ID / SA revision / source UI: `purchase-order` / 1 / [UI revision 1](../../../frontend/purchase-order/ui-spec.md)
- Status: **approved** 2026-11-04. Approval evidence: owner 2026-11-04: "อนุมัติ purchase-order revision 1".
- ADR: [ADR-0041](../../../../adr/0041-purchase-order-document.md) (Accepted)
- Bundle: this file, [api-contract.md](api-contract.md), [database-diagram.md](database-diagram.md), [sequence-diagram.md](sequence-diagram.md); flow [diagram/purchase-order-flow.md](../../../../diagram/purchase-order-flow.md); TODO [task/todo/purchase-order.md](../../../../task/todo/purchase-order.md)
- Service: `backend-api-master` (`api-master`), schema `partner`. No new service, container, volume, cache or package.

| ID | Decision |
|---|---|
| SA-PO-01 | **Tables** (migration `20261104090000_purchase_order`, additive): `purchase_order`, `purchase_order_line`, `purchase_order_charge`, `purchase_order_line_photo`. Header and charges are shaped like `memo_receive` (vendor + one address snapshot, currency, totals, `approved_at/by`, `version`). Lines are shaped like `quotation_line` MANUAL lines (with `stone_code_id` + snapshot and free-text `location`, Q-PO-06) **without** the stock columns, plus `purchased_pcs` int default 0 and `purchased_weight_ct` numeric(12,3) default 0 with CHECK `0 ≤ purchased ≤ ordered` (pcs and weight). |
| SA-PO-02 | **Engine:** `PurchaseOrderService` uses `TradeDocumentEngine` with the vendor party adapter (shared with Memo Receive / Memo Return), `createStatus: PENDING_APPROVAL`, `editableStatuses: [PENDING_APPROVAL]`, no `lineOmit` (Stone Code and Location are kept), and a line hook for photos (as SA-MR-17). |
| SA-PO-03 | **Status:** `PENDING_APPROVAL` → `APPROVED` only, by `purchaseOrder.approve`. Update and delete need `PENDING_APPROVAL`, else `PURCHASE_ORDER_STATUS_INVALID` (409). No reject, cancel or un-approve in rev 1 (Q-PO-02/12). |
| SA-PO-04 | **Approve** (Q-PO-04): one `WRITE_TX`: `UPDATE purchase_order SET status='APPROVED', approved_at, approved_by, version+1 WHERE id AND version AND status='PENDING_APPROVAL'`; 0 rows → re-read for NOT_FOUND / CHANGED / STATUS_INVALID. Lines keep `purchased_* = 0`, so every line is outstanding for its full pcs / weight. No `memo_stock`, Stock ID or inventory row is written. Log `purchase_order.approved` (id, docNo, line count). |
| SA-PO-05 | **"Sent to Purchase"** means: a line of an `APPROVED` PO with `purchased_pcs < pcs OR purchased_weight_ct < weight_ct` is available to the Purchase page. The Purchase service (later revision) is the only writer of `purchased_*`; this revision only defines the columns and index `purchase_order_line (purchase_order_id)`. |
| SA-PO-06 | **Lines:** `source` MANUAL only — `STOCK` and `memoStockId` are rejected (`VALIDATION_ERROR`), so a PO can't be filled from From Stock or Memo Stock (Q-PO-05). Optional `stoneCodeId` (active stone code or the stored one). Bounds as SA-QT-07: 1–200 lines, attributes ≤ 60, lot ≤ 40, location ≤ 40 (free text), cer type ≤ 20, cer no ≤ 60, pcs 0–999,999, weight 0–99,999.999, unit price ≥ 0 (2 dp), line discount, item note ≤ 500, photos ≤ 5. |
| SA-PO-07 | **Header and totals:** as SA-MR-09: active vendor + one of its addresses (or the stored ones), snapshots; currency active or stored; exchange rate required for a foreign currency; due date ≥ doc date; ref ≤ 100; note ≤ 500; server totals with the quotation calculator (line % ≤ 100, line amount discount ≤ gross, document amount discount ≤ subtotal). |
| SA-PO-08 | **Numbers:** Document Setup key `purchase-order` (exists, code `PO`); `NumberedDocument` gains `purchaseOrder` (advisory key `partner.purchase_order.plain_running_no`); Document Setup `used` also counts `purchase_order`. `nextNumber` previews. |
| SA-PO-09 | **Permissions:** catalog leaf `purchase-order` (exists); `MasterMenu` gains it. VIEW = list / get / options / nextNumber / photo read; ADD = create + photo upload; EDIT = update + photo upload; DELETE = delete; APPROVE = approve (the creator may approve). Mutations need CSRF. No auth migration. |
| SA-PO-10 | **Options:** `purchaseOrder.options {vendorId?}` = `memoReceive.options` shape plus stone codes (vendors + addresses, currencies, company currency, charge types, numbering, stone lists with codes). Gated by `purchase-order:VIEW` only. |
| SA-PO-11 | **Photos:** `POST /api/v1/purchase-order/photos` and `GET /api/v1/purchase-order/photos/:id`, reusing the Quotation photo HTTP code (JPEG/PNG, magic bytes, ≤ 5 MB), `@gms/storage` module `purchase-order-photo`, source `purchase_order.line-photo`, and the **same process-wide limiter** (3 uploads, 6 downloads). Upload: ADD or EDIT + CSRF; read: VIEW. A foreign photo id → `PURCHASE_ORDER_PHOTO_INVALID`. Bytes kept permanently (ADR-0030). |
| SA-PO-12 | **Infra:** one nginx location `^~ /api/v1/purchase-order/photos` → `api-master:3201`, `client_max_body_size 6m`, in `docker/nginx/gms-dev.conf` (integration-owned; parent edits) and the production profile. No other container, volume or image change. |
| SA-PO-13 | **List:** `purchaseOrder.list` keyset `(doc_date desc, created_at desc, id desc)`, ≤ 50 rows, filters status / vendor / date range (≤ 366 days), search doc no / vendor name / ref (≤ 100 chars, escaped). Daybook = this list. |
| SA-PO-14 | **Errors and audit:** `PURCHASE_ORDER_NOT_FOUND` 404, `_CHANGED` 409, `_STATUS_INVALID` 409, `_REFERENCE_INVALID` 422 (field named), `_PHOTO_INVALID` 422, plus the shared `VALIDATION_ERROR`, `PERMISSION_DENIED`, `CSRF_INVALID`, `PARTNER_UNAVAILABLE`. Logs `purchase_order.created/updated/deleted/approved` with ids and doc no only — never prices or vendor names. |
| SA-PO-15 | **Not in this revision:** the Purchase (PU) document and its writes to `purchased_*`; the Purchase Outstanding report; reject / cancel / un-approve; print / Excel; PRICE masking. |

Capacity: one save writes ≤ 200 lines, ≤ 1,000 photo links and 4 charge rows in one transaction; approve is a single-row update. Lists are keyset-bounded (≤ 50). Photo traffic shares the existing limiter, so host memory and pool use do not grow.
