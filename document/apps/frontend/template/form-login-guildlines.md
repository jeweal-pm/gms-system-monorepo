# Form Guidelines (Frontend)

## จังหวะการแสดง error
- ไม่แสดง error ขณะ user ยังพิมพ์ครั้งแรก
- ตรวจครั้งแรกเมื่อออกจากช่อง (onBlur)
- หลังจากมี error แล้ว ตรวจใหม่ทุกครั้งที่พิมพ์ (onChange) เพื่อให้ error หายทันทีเมื่อแก้ถูก
- กด Submit แล้วตรวจทุกช่อง และเลื่อนไปที่ช่องแรกที่ผิด

## ปุ่ม Submit
- ไม่ disable ปุ่มเพราะฟอร์มยังไม่ถูก (user จะไม่รู้ว่าผิดตรงไหน)
- disable และแสดง loading เฉพาะตอนกำลังส่งข้อมูล ป้องกันกดซ้ำ

## การจำกัดสิ่งที่พิมพ์ได้
- **บล็อกไม่ให้พิมพ์:** ใช้กับช่องที่รับแค่ตัวเลขชัดเจน (เบอร์โทร, เลขบัตร, OTP)
- **ให้พิมพ์ได้แล้วแจ้ง error:** ใช้กับช่องอื่นทั้งหมด (email, password)
  เพราะการบล็อกเงียบๆ ทำให้ user สับสนว่าทำไมพิมพ์ไม่ติด
- ตัดช่องว่างหน้า-หลัง (trim) อัตโนมัติก่อนตรวจ ยกเว้นช่อง password

## Attribute ที่ต้องใส่
- `autocomplete` ทุกช่องที่เกี่ยวข้อง (email, current-password, new-password)
- `inputMode="numeric"` สำหรับช่องตัวเลข เพื่อให้มือถือขึ้นแป้นตัวเลข
- `label` ทุกช่อง ห้ามใช้ placeholder แทน label
