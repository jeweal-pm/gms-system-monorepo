## Paths and ownership

Record route paths, feature/component/hook/model files, shared components, and the assigned
scope. Follow the current frontend structure; do not assume an apps/web-frontend folder.
Mark manifest, lockfile, provider, proxy, and composition changes integration-owned.

## Components and state

Use TypeScript, established naming/export patterns, and Tailwind tokens. Record server/client
boundaries, local UI state, TanStack Query server state, auth client use, and component props.
Match the approved UI spec, semantic HTML, keyboard/focus behavior, and deterministic hydration.

## Delivery

Link UI TODO, dependency proposals, required SA contracts, and test/acceptance documents.
Write feature documents here, handoffs under document/coordination/, and completion evidence
under document/task/done/. Templates are examples, not approved design decisions.
