# Open questions: app-shell-tabs

Owner answers 2026-11-02 (Q-TAB-01…04). Q-TAB-05…08 are proposed defaults, confirmed by the approval of revision 1.

| ID | Question | Answer |
|---|---|---|
| Q-TAB-01 | A sidebar menu whose page is already open? | **Switch to its tab** (one tab per page; another saved document is another tab). |
| Q-TAB-02 | How many tabs, and at the limit? | **15, then refuse** with a message; nothing closes by itself. |
| Q-TAB-03 | Closing a tab with unsaved typed data? | **Ask first**; Close all asks once with the count. Tabs with unsaved data show a dot. |
| Q-TAB-04 | After a refresh or the next sign-in? | **Reopen the same tabs** (remembered per user in this browser); pages load fresh. |
| Q-TAB-05 | Tab title | Proposed: the last breadcrumb ("Stone Code"); saved documents add their number ("Memo Out · MO-1"). |
| Q-TAB-06 | What does Close all leave open? | Proposed: Home, as the only tab. |
| Q-TAB-07 | What does the count box do? | Proposed: shows the number of open tabs and opens a list of them to switch to or close; disabled with one tab. |
| Q-TAB-08 | Source 02 (empty strip, disabled controls) | Proposed: the loading state right after sign-in, and the disabled look of the count box and Close all. |
