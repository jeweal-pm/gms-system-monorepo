# Open questions: stock-card (UI revision 1)

Status: **pending-review**. Nothing is answered beyond the owner request and the design images (see [ui-spec](ui-spec.md)). Each row has a **recommended default**; approving revision 1 "with the defaults" accepts all of them, or the owner answers any ID. **requires-sa** rows also wait for the SA bundle. Evidence: C = code or approved spec, O = owner/design, A = assumption.
